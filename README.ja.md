# Ghidra Scripts

[English](README.md)

Ghidraでのリバースエンジニアリングやマルウェア解析を支援する、PythonおよびJavaスクリプト集です。

## ApplySig.py

IDA FLIRTの`.sig`ファイルを読み込み、現在のプログラム内の関数と照合します。一致した既定名の`FUN_`関数をシグネチャ内の名前へ変更します。**Tools > Function ID > ApplySig**から実行できます。

## ApplyFlirtSignatures.java

`ApplySig.py`を拡張した、より厳密で包括的なFLIRT解析を行うネイティブJava実装です。GhidraのScript Managerから実行します。

追加実装した主な機能は次のとおりです。

- Rizinを起動せず、`validation.json`などのサイドカーファイルも使用せずに、Ghidra内だけで動作します。
- バイナリIDASGNバージョン5から10を解析し、バージョン6から10の圧縮シグネチャにも対応します。
- プログラムを変更する前に、完全パターン、CRC、末尾バイトを検証します。
- 既存関数に加え、エントリーポイント、呼び出し、参照、リロケーション、型付きポインター、ポインターテーブル、コード境界、希少なシグネチャアンカーから候補を検出します。
- 検証済みの未定義位置に関数を作成し、既存関数内の候補は十分な構造的根拠がある場合に限って安全に分割します。
- FLIRTの参照グラフと構造的根拠を使って候補を解決し、曖昧さが残る場合は適用せず、ブックマークとリピータブルコメントに記録します。
- Rustの候補がレガシーマングルのハッシュや`.llvm`接尾辞だけで異なる場合は、共通のデマングル名を付け、候補のハッシュをリピータブルコメントに残します。
- モジュール内のオフセットが0でないpublicシンボルは、呼び出しやエントリーポイントなど関数開始点の独立した証拠がある場合に限って関数にし、それ以外はラベルにします。
- 残った候補のデマングル名に共通の意味がある場合（RustまたはMSVCのC++）は、`ambig_`で始まる近似名かラベルを付けます。たとえば、別々のクラスのdeleting destructorには`scalar_deleting_destructor`を使います。共通するのが所属する型やモジュールだけの場合は、`ambig_type_`で始まるラベルを付けます。
- ユーザー定義の関数名と、ローダー・エクスポート・PDB由来の関数名を保持し（ローダーが付ける仮の名前`entry`と`tls_callback_<n>`は、強い一致の場合に限って置き換えます）、適用したシンボルをシグネチャのライブラリ名前空間にまとめ、対応するRustシンボル（レガシーとv0のマングル）を正規化またはデマングルします。
- どのシグネチャが関数に名前を付けたかを記録します。複数のシグネチャを順に適用しても、前の名前を別の識別子で置き換えることはありません。食い違いがあれば前の名前を残し、ブックマークとリピータブルコメントに記録します。
- `--dry-run`による解析と、`--report-json`による任意のJSONレポート出力に対応します。`--dry-run`はプログラムを変更せずに、本番で作成・改名する関数の数を数えます。

## findcrypt.py

既知の暗号関連定数を、完全一致する配列、疎な配列、即値オペランドから検索し、一致箇所へラベルやコメントを追加します。

メモリをまとめて読み出し、定数ごとにGhidraへ検索を依頼する代わりにPythonのバイト検索で調べます。x86では、即値定数のバイト列を含む命令だけをデコードします。すべての命令をデコードしたい場合は、スクリプト先頭の`USE_X86_BYTE_PREFILTER`を`False`にしてください（参照先アドレスが定数と等しいRIP相対オペランドも報告されるようになります）。x86以外のプロセッサでは常に全命令をデコードします。タスクをキャンセルするとスキャンも停止します。PyGhidra（CPython 3）が必要で、Jythonでは動作しません。

## shellcode_hash_search.py

即値やDWORD配列をシェルコードAPIハッシュDBで検索します。解決したAPI名をコメントとして追加し、連続する一致箇所から構造体を作成することもできます。

## struct_typer.py

構造体メンバーまたはスタック変数の名前を、開いているデータ型マネージャー内の関数定義と照合し、対応する関数ポインター型を適用します。照合前に正規表現で名前のプレフィックスを除去することもできます。

## make_sc_hash_db.py

指定ディレクトリ内のPEファイルからエクスポートを読み取り、代表的なシェルコードAPIハッシュを計算して、`shellcode_hash_search.py`用のSQLite DBを生成する単体Pythonツールです。`pefile`パッケージが必要です。

## consts.py

`findcrypt.py`が使用する定数データベースです。直接実行すると、対応しているアルゴリズムと定数名を表示します。

## 同梱データ

`sc_hashes.zip`には、`shellcode_hash_search.py`が使用する構築済みの`sc_hashes.db`が含まれています。`sc_hashes.db`をスクリプトと同じディレクトリへ展開するか、実行時のダイアログでDBを選択してください。

手元のPEファイルからDBを作成する場合は、次のコマンドを実行します。

```text
python make_sc_hash_db.py <db_path> <dll_dir>
```
